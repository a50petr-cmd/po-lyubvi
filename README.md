# По любви

Сайт салона «По любви» в Электростали. У каждого раздела своя страница. Запись подключается к YCLIENTS, заявки с формы видит админка.

## Как открыть

Из папки проекта:

```bash
python server.py
```

Сайт: http://127.0.0.1:17342/

Админка: http://127.0.0.1:17342/admin.html

Пароль при первом запуске печатается в консоли и записывается в `admin-password.txt`. После входа его нужно сменить. Файл с паролем после этого можно удалить.

## YCLIENTS

В админке, в поле онлайн-записи, вставьте ссылку вида `https://n123456.yclients.com` или только число. Его берут в кабинете YCLIENTS: «Онлайн-запись» → форма → ссылка или код кнопки. Пока поле пустое, кнопка «Записаться» открывает заявку на сайте. Когда число сохранено, та же кнопка открывает виджет YCLIENTS.

Ключ API в этих файлах не хранится и для кнопки записи не нужен. Учётные данные YCLIENTS в репозиторий не входят.

Страницы можно открыть и без админки, как статические файлы:

```bash
python -m http.server 17341
```

Тогда сайт будет на http://127.0.0.1:17341/. Запись и админка в этом режиме не работают: для них нужен `server.py`.
