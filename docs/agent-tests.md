# Проверка агентов Claude Code (5 минут, дёшево)

Запускать в Claude Code из папки проекта. Каждую проверку — в новой сессии (`/clear` между ними).

## 1. Агенты видны
Напишите: «Какие субагенты есть в этом проекте? Перечисли имя и модель.»
Ожидаем: 9 агентов — analyst (haiku), copywriter (sonnet), designer (sonnet), developer (sonnet), editor (haiku),
marketer (sonnet), qa (haiku), seo (sonnet), strategist (sonnet).
Если список пустой — перезапустите Claude Code из папки проекта (`/exit`, затем `claude`).

## 2. Haiku-агент работает с файлами (analyst)
Напишите: «Используй агента analyst: сверь цены в content.json (priceGroups → Маникюр) с source/price-extract.txt.
Выпиши расхождения в docs/research.md. Только раздел Маникюр.»
Ожидаем: появился docs/research.md с таблицей «услуга · на сайте · в прайсе · совпадает?». Агент не открывал фото.

## 3. Правило «не выдумывать» (editor)
Напишите: «Используй агента editor: поменяй цвет месяца на ноябрь.»
Ожидаем: агент НЕ придумывает название и цвет, а спрашивает их (или ставит TODO). Если придумал — агент работает
неправильно, напишите об этом Claude в чате.

## 4. Контролёр не правит код (qa)
Напишите: «Используй агента qa: проверь index.html на ширине 390 px по чек-листу из CLAUDE.md.»
Ожидаем: docs/qa-report.md с таблицей ошибок; файлы сайта НЕ изменены (`git status` показывает только docs/qa-report.md).

После проверок: `git status` — лишнего быть не должно. docs/research.md и docs/qa-report.md можно оставить.
