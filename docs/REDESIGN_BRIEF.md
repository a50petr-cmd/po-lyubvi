# ТЗ на редизайн «По любви» (для кодинг-агента)

Полная стратегия: документ «По любви: стратегия сайта и продвижения» (Claude). Контекст прошлой работы: AGENT_HANDOFF.md.

## Цель
Сайт должен приводить к записи. Главная метрика — цель Метрики `booking_done` (запись создана в YCLIENTS).

## Не трогать
- Логотип `logo-title.svg` и подпись «Салон красоты» текстом (только в шапке, из героя убрать).
- Палитру по духу (серо-бежевая, графит). Прайс — только из `Прайс love 2026 итог.pdf` / content.json.
- Не выдумывать цифры, отзывы, награды.

## Стек
- Astro (статическая сборка). Данные — content.json. Все тексты и цены в итоговом HTML, не через JS.
- Tailwind допустим; блоки HyperUI/Preline как основа, перекрасить в дизайн-систему.
- Шрифты локально (woff2): Cormorant Garamond (заголовки), Manrope (текст). Без Google Fonts.
- Деплой: GitHub Actions → FTP/SSH на хостинг (Спринтхост или Beget), секреты в GitHub Secrets.

## Дизайн-система
- Фон #F3EFE8, текст/кнопки #1E1C1A, вторичный #8A847B, акцент = colorOfMonth.hex.
- Фото 3:4, радиус 12px, WebP/AVIF ≤200 КБ, srcset.
- Анимации: только fade-in при скролле и свайп галереи; prefers-reduced-motion.

## Фото
Выбирать по `photos/INDEX.md`. Фото салона от владелицы — `photos/salon/` (вход с улицы → Контакты; ресепшен и холл → блок «Салон»/Стандарты; кабинет косметолога → Эстетика). salon-05 — в кадре клиенты: не ставить без согласия или кадрировать.

## Главная (сверху вниз)
1. Герой: фото на всю ширину, H1 «Маникюр и педикюр в Электростали», слоган, бейдж 5,0 «Хорошее место 2026», кнопки «Выбрать время» (YCLIENTS) и «WhatsApp».
2. Блок «Запись онлайн»: кнопка выбора времени в YCLIENTS + 3 шага «услуга → мастер → время» (вариант Б со слотами — позже).
3. Услуги: 5 карточек с фото и ценой «от».
4. Акция −15% первый визит (с условиями).
5. Работы: лента со свайпом + фильтры.
6. Мастера и грейды.
7. Отзывы (виджет Яндекс Бизнеса или 3–4 цитаты + ссылка).
8. Стандарты (стерилизация, технолог, косметика).
9. Цвет месяца — компактно, с фото.
10. FAQ (FAQPage).
11. Контакты: Яндекс Карта, адрес, «ост. Эльград, 285 м», часы.
Мобильная нижняя панель на всех страницах: Записаться · Позвонить · WhatsApp. Бургер-меню.

## Страницы услуг (manikyur, pedikyur, vzglyad, estetika, massazh) + новая podarochnyj-sertifikat
H1 «<Услуга> в Электростали», текст 300–600 слов, таблица цен по 4 грейдам как в PDF, работы, FAQ, запись с предвыбором категории.

## YCLIENTS
- СЕЙЧАС делаем только вариант А: форма https://n1270388.yclients.ru (кнопки data-book; на страницах услуг — с нужной категорией). Форма YCLIENTS сама показывает свободные дату и время без ПДн.
- ПОЗЖЕ (не делать без команды): вариант Б — `public/api/slots.php` (book_staff / book_dates / book_times), токен в .env на хостинге, кэш 5–10 мин.

## SEO / аналитика
- title ≤60, description, canonical, OG 1200×630, robots.txt, sitemap.xml, 404.
- JSON-LD: BeautySalon (+NailSalon), Service+Offer, FAQPage, BreadcrumbList.
- Метрика: цели booking_open, booking_done, slot_click, call, whatsapp, telegram, route, form_sent, price_open. Вебвизор.
- Подвал: «ранее Нэйл Персона», реквизиты ИП/ООО, политика, согласие ПДн (отдельный документ), cookie-плашка.

## Приёмка
Lighthouse mobile ≥90 (SEO 100), нет горизонтального скролла на 360px, тестовая запись засчитана целью, цены сверены с PDF.
