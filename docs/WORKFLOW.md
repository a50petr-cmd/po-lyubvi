# Как работаем в этой папке

## Кто что делает
| Где | Роль | Модель | Для чего |
|---|---|---|---|
| Чат Claude (приложение) | Стратег, арт-директор, ревью | — | Стратегия, концепции, разбор правок владелицы, документы для клиента. Без кода. |
| Claude Code (тариф Pro) | Агенты из `.claude/agents/` | haiku / sonnet | Многошаговые задачи с кодом и файлами |
| Cursor (режим Auto) | Разработчик «на подхвате» | Auto | Точечные правки кода по готовому ТЗ. Правила — `.cursor/rules/project.mdc` |

## Cursor — два способа
**1. В редакторе Cursor (режим Auto, без доп. трат).** Правила лежат в `.cursor/rules/`:
- `project.mdc` подключается всегда;
- `@developer` — код по ТЗ: «@developer сделай нижнюю панель записи в index.html по REDESIGN_BRIEF, раздел Главная»;
- `@editor` — одна правка: «@editor цвет месяца ноябрь: Тёплый беж, #C8B6A6».
Cursor также читает `AGENTS.md` в корне → он отсылает к CLAUDE.md.

**2. Облачный агент Cursor (задачи даёт Claude из чата).** Claude ставит задачу облачному агенту Cursor на репозиторий
`a50petr-cmd/po-lyubvi`, агент работает в отдельной ветке и открывает PR в `redesign`. Вы смотрите PR и сливаете.
- Модель по умолчанию — `composer-2.5` (своя модель Cursor, дешевле всего); для простых задач — `gemini-3.7-flash-high`.
- Облачный агент видит только то, что запушено в GitHub. Локальные изменения сначала «выложи».
- Облачные задачи могут списываться сверх подписки — проверьте Cursor → Settings → Usage перед первой задачей.
Кому что: Cursor — механическая вёрстка по готовому ТЗ (страницы услуг по шаблону, правки CSS);
Claude Code — задачи, где нужно думать и связывать файлы; чат Claude — стратегия, дизайн, ревью PR.

| Агент | Модель | Когда звать |
|---|---|---|
| editor | haiku | цвет месяца, новость, цена, телефон — одна правка |
| analyst | haiku | сверка цен с PDF, сбор конкурентов, обновить INDEX фото |
| qa | haiku | перед показом владелице и перед «выложи» |
| developer | sonnet | вёрстка Astro, страницы, запись, деплой |
| copywriter | sonnet | тексты страниц услуг, FAQ, title/description |
| seo | sonnet | Метрика и цели, JSON-LD, sitemap |
| designer | sonnet | 3 концепции первого экрана, потом DESIGN.md |
| strategist | sonnet | редко: пересмотр структуры или каналов |
| marketer | sonnet | после запуска: тексты рекламы, недельный отчёт |
Opus не используем по умолчанию: на Pro лимиты быстро кончаются. Разово — для сложного решения, если доступен.

## Правила экономии
1. Одна задача — одна сессия. Закончили — `/clear`. Длинная сессия — `/compact`.
2. Звать агента по имени и давать точные файлы: «developer: правь src/pages/manikyur.astro по DESIGN.md, раздел Карточки».
3. Картинки не открывать — выбирать по `photos/INDEX.md`. Скриншоты делает только qa и designer, 2–3 штуки.
4. Агенты передают работу через файлы в `docs/` (research, strategy, DESIGN, qa-report, changelog), а не через историю чата.
5. Не просить «посмотри весь проект». CLAUDE.md уже даёт контекст.
6. Мелкую правку кода — в Cursor, а не в Claude Code.
