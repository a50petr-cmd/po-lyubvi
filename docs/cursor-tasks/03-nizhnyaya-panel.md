# Задача 03. Нижняя панель «Записаться · Позвонить · WhatsApp» на телефоне

Ветка: `redesign`. Образец вида — вариант, который выберет владелица (concepts/first-screen.html, блок `.dock`).
Пока выбора нет — делаем нейтрально в текущей палитре styles.css.

## Сделать
1. Во всех публичных HTML перед `</body>`: `<nav class="dock" aria-label="Быстрые действия">` с тремя ссылками:
   - «Записаться» — `href="contacts.html#booking" data-book` (существующая логика mountBooking откроет YCLIENTS);
   - «Позвонить» — `tel:+79295551887`;
   - «WhatsApp» — `https://wa.me/79295551887`, target=_blank, rel=noopener.
2. styles.css: `.dock` — position:fixed; left/right/bottom:0; три колонки 1.4fr 1fr 1fr; высота кнопок ≥ 46px;
   нижний отступ `calc(8px + env(safe-area-inset-bottom))`; цвета — из существующих переменных styles.css;
   «Записаться» — основная (тёмная) кнопка. Показывать только при ширине < 900px.
3. На ширине < 900px: скрыть плавающую кнопку Telegram (она перекрывается панелью) и добавить body `padding-bottom`,
   равный высоте панели, чтобы футер не прятался.
4. Убедиться, что `mountBooking` вешает обработчик и на кнопку панели (если панель вставлена после вызова — вызвать повторно или использовать делегирование).

## Не делать
Не менять шапку, героя и остальные блоки. Не трогать content.json.

- на 1440 px панели нет, Telegram-кнопка на месте;
- «Записаться» открывает запись YCLIENTS так же, как кнопка в шапке;
