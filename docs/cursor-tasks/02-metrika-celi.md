# Задача 02. Подготовить Яндекс Метрику и цели (без номера счётчика)

Ветка: `redesign`. Номера счётчика пока нет — код должен работать «вхолостую», пока номер пустой.

## Сделать
1. В `site.js` в самом начале: константа `const YM_ID = null; // TODO: номер счётчика Метрики`.
   Если YM_ID задан — подключить стандартный код Метрики (tag.js) с параметрами
   `clickmap:true, trackLinks:true, accurateTrackBounce:true, webvisor:true`. Если null — ничего не грузить.
2. Функция `goal(name)` — вызывает `ym(YM_ID,'reachGoal',name)`, если Метрика подключена; иначе пишет в console.debug.
3. Повесить цели (делегирование кликов на document, не на каждую кнопку):
   - `booking_open` — клик по любому элементу с `data-book`;
   - `call` — клик по ссылке `tel:`;
   - `whatsapp` — ссылка на `wa.me`;
   - `telegram` — ссылка на `t.me`;
   - `route` — элемент с `data-route`;
   - `price_open` — открытие `<details>` в каталоге услуг (событие toggle, только при открытии);
   - `form_sent` — успешная отправка формы заявки (найти место в site.js, где форма отправляется).
4. В privacy.html — абзац: сайт использует Яндекс Метрику (cookie, вебвизор) для статистики посещений.

## Не делать
Не подключать Google Analytics. Не менять вёрстку и тексты, кроме абзаца в privacy.html.

## Готово, когда
- при YM_ID = null в Network нет запросов к mc.yandex.ru, в консоли при кликах видны `goal: booking_open` и т.д.;
- при подстановке любого числа скрипт Метрики начинает грузиться;
- список изменённых файлов + строка в docs/changelog.md.
