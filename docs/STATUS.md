## Принятые решения
- Цель сайта — записи; главная метрика — цель Метрики `booking_done`.
- Запись: сейчас только форма YCLIENTS n1270388 (вариант А). Блок «ближайшие окна» через API — позже.
- Стек редизайна: Astro (статическая сборка, тексты и цены в HTML), шрифты локально, без Google Fonts/Analytics.
- Хостинг/домен: оформить на владелицу. Рекомендация — Спринтхост или Beget (~2 000–2 500 ₽/год).
  Reg.ru допустим, но продление .ru там 1 199 ₽/год против 339–399 ₽.
- Инструменты: чат Claude — стратегия, дизайн, ревью; Claude Code (Pro) — агенты haiku/sonnet, Opus не по умолчанию;
  Cursor (Auto) — точечный код по файлам-заданиям `docs/cursor-tasks/`.
- Агенты Claude Code: `.claude/agents/` (9 шт.): analyst, editor, qa — haiku; developer, copywriter, seo, designer,
  strategist, marketer — sonnet. Команды `/agents` в новой версии нет — вызывать фразой «Используй агента X: …».
- Cursor: правила `.cursor/rules/` (project — всегда, @developer, @editor) + `AGENTS.md`.
- Облачный агент Cursor доступен из чата Claude (ключ «Claude»), но не использовать без проверки Usage — лимит Cursor исчерпан.
- Пётр будет сам обновлять сайт после запуска.
