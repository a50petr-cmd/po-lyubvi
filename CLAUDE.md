# Сайт салона «По любви» (Электросталь)

Статический сайт салона красоты. Локомотив — маникюр и смарт-педикюр; также взгляд (брови/ресницы), эстетика (без инъекций), массаж.
Цель сайта — записи. Главная метрика: цель Метрики `booking_done`.

## Где что лежит
- `docs/REDESIGN_BRIEF.md` — ТЗ на редизайн. Читать перед любой работой над дизайном и вёрсткой.
- `docs/WORKFLOW.md` — как работаем, какие агенты, какие модели.
- `docs/AGENT_HANDOFF.md` — история прошлой работы в Cursor. Читать только при необходимости.
- `content.json` — единственный источник текстов, цен, контактов.
- `photos/INDEX.md` — каталог фото по категориям. Выбирать фото ТОЛЬКО по нему.
- `source/` — сырьё клиента (PDF-прайс, логотип .ai, HEIC). Не в git.

## Правила (для всех агентов)
1. Не открывать картинки из `photos/` и файлы из `source/` без прямой просьбы — смотреть `photos/INDEX.md`.
2. Не выдумывать цены, цифры, отзывы, имена мастеров. Нет данных — оставить `TODO:` и сказать об этом.
3. Цены — только из `content.json` (сверен с PDF «Прайс love 2026 итог»).
4. Тексты и цены должны быть в HTML, а не дорисовываться JS.
5. Без Google Fonts и Google Analytics. Только Яндекс Метрика.
6. Логотип — `logo-title.svg` + подпись «Салон красоты» текстом. Не заменять растровым.
7. Секреты, пароли, `admin.json`, `requests.json`, `source/` — никогда не коммитить.
8. Работа над редизайном — в ветке `redesign`. `master` = живой сайт.
9. Одна задача — одна сессия. Результат записывать в файл, а не только в чат.
